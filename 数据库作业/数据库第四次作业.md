### 1. 简答题

#### （1）试述 SQL 的特点

SQL（Structured Query Language）是一种集数据定义、数据操纵、数据控制于一体的关系数据库语言，主要特点如下：

- 一体化：既可定义数据库对象（DDL），又可进行查询和更新（DML），还可进行授权与控制（DCL）。
- 非过程化：用户只需说明“做什么”，不必说明“怎么做”。
- 面向集合：一次操作可处理一个集合中的多条记录。
- 使用方式灵活：既可交互式使用，也可嵌入高级语言中使用。
- 语言简洁：语法接近自然语言，易学易用。

#### （2）什么是视图？视图有什么优点？

视图是由一个或多个基本表（或视图）导出的虚表，本身一般不存储数据，数据来自定义视图的查询结果。

视图的优点：

- 简化查询：将复杂查询封装起来，使用更方便。
- 提高安全性：可只向用户开放部分行或列。
- 增强逻辑独立性：当基本表结构变化时，可通过调整视图减少对应用的影响。
- 统一数据表示：对同一数据可提供不同角度的用户视图。

### 2. 关系代数转 SQL 表达式

已知关系：$X(A, B, C, D)$，$Y(C, D, E, F)$。

#### （1）$\Pi_{C,D}(\sigma_{A=10}(X))$

SELECT DISTINCT C, D
FROM X
WHERE A = 10;

#### （2）$X \bowtie Y$

SELECT X.A, X.B, X.C, X.D, Y.E, Y.F
FROM X JOIN Y
ON X.C = Y.C AND X.D = Y.D;

#### （3）$X \underset{X.C=Y.C}{\bowtie} Y$

SELECT X.A, X.B, X.C AS XC, X.D AS XD, Y.C AS YC, Y.D AS YD, Y.E, Y.F
FROM X JOIN Y
ON X.C = Y.C;

#### （4）$\Pi_{C,D}(X) - \Pi_{C,D}(Y)$

SELECT DISTINCT X.C, X.D
FROM X
WHERE NOT EXISTS (
    SELECT 1
    FROM Y
    WHERE Y.C = X.C AND Y.D = X.D
);

### 3. SQL 综合应用题

已知：

- 学生表：$S(Sno, Sname, Sage, Ssex, Sdept)$
- 课程表：$C(Cno, Cname, Ccredit)$
- 选课表：$SC(Sno, Cno, Grade)$

#### （1）查询缺考课程 C1 的学生信息，并按学号升序排序

SELECT S.*
FROM S JOIN SC ON S.Sno = SC.Sno
WHERE SC.Cno = 'C1' AND SC.Grade = -1
ORDER BY S.Sno ASC;

#### （2）查询同时选修了 C1 和 C5 号课程的所有学生姓名和所在系

SELECT S.Sname, S.Sdept
FROM S JOIN SC ON S.Sno = SC.Sno
WHERE SC.Cno IN ('C1', 'C5')
GROUP BY S.Sno, S.Sname, S.Sdept
HAVING COUNT(DISTINCT SC.Cno) = 2;

#### （3）查询学生“张三”选修的课程的总学分

SELECT SUM(C.Ccredit) AS TotalCredit
FROM S JOIN SC ON S.Sno = SC.Sno
JOIN C ON SC.Cno = C.Cno
WHERE S.Sname = '张三';

#### （4）把 CS 系学生“李四”选修 C2 课程的信息加入选课表

INSERT INTO SC (Sno, Cno, Grade)
SELECT S.Sno, 'C2', NULL
FROM S
WHERE S.Sname = '李四' AND S.Sdept = 'CS';

#### （5）将课程名为“数据库”的学分修改为 3

UPDATE C
SET Ccredit = 3
WHERE Cname = '数据库';

#### （6）删除所有姓“张”且名字中带有“雨”字的学生信息

DELETE FROM S
WHERE Sname LIKE '张%' AND Sname LIKE '%雨%';

#### （7）创建 IS 系学生的选课视图（学号、姓名、课程名、成绩）

CREATE VIEW V_IS_SC AS
SELECT S.Sno, S.Sname, C.Cname, SC.Grade
FROM S JOIN SC ON S.Sno = SC.Sno
JOIN C ON SC.Cno = C.Cno
WHERE S.Sdept = 'IS';

#### （8）在第（7）题视图基础上，查询成绩为 90 分的学生姓名和课程名

SELECT Sname, Cname
FROM V_IS_SC
WHERE Grade = 90;

#### （9）授予用户 U1 对 SC 的查询权限和对 Grade 的更新权限，并允许转授

GRANT SELECT ON SC TO U1 WITH GRANT OPTION;
GRANT UPDATE (Grade) ON SC TO U1 WITH GRANT OPTION;
