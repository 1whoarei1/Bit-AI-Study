## 1. 油井问题

### 题目描述

主油管道为东西向，需要确定主管道的南北位置（Y坐标），使得所有南北向油井到主管道的距离之和最小。要求在**线性时间**内完成。

- 油井数量：1 ≤ N ≤ 2,000,000
- 坐标范围：0 ≤ X, Y < 2³¹
- 输入格式：每行为 `X,Y`（逗号分隔）
- **注意：使用快速排序不给分**

### 输入样例

```
41,969978
26500,413356
11478,550396
24464,567225
23281,613747
491,766290
4827,77476
14604,597006
292,706822
18716,289610
5447,914746
```

### 输出样例

```
597006
```

### 解题思路

由于主管道是东西向的（水平），每口油井到主管道的距离仅取决于其 Y 坐标，等于 |Y_i − Y_pipeline|。问题转化为：

> 在数轴上给定 N 个点 Y₁, Y₂, …, Y_N，求一点 Y_opt 使得 ∑|Y_i − Y_opt| 最小。

这是经典的 **L1 中位数问题**。绝对值函数之和在**中位数**处取得最小值。

**证明**：设排序后的 Y 坐标为 y₁ ≤ y₂ ≤ … ≤ y_N。对于任意位置 t：

- 若 N 为奇数，t = y_{(N+1)/2} 时最小
- 若 N 为偶数，t ∈ [y_{N/2}, y_{N/2+1}] 内任意值均可，题目要求**最小**值，取 y_{N/2}

### 算法设计

使用**快速选择算法（Quickselect）**在 O(N) 期望时间内找到第 K 小的元素（即中位数）：

1. 每次选择一个 pivot，将数组划分为小于等于 pivot 和大于 pivot 两部分
2. 根据 pivot 的位置与目标 K 的关系，递归在一侧继续查找
3. 采用三数取中法优化 pivot 选择，避免最坏情况

**关键特性**：快速选择 ≠ 快速排序。快速选择只递归一侧，平均 O(N)，而快速排序递归两侧，O(N log N)。

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(N) 期望（最坏 O(N²)，可通过 Median-of-Medians 达到严格 O(N)） |
| 空间复杂度 | O(N) 存储 Y 坐标 |

### 正确性验证

样例数据 Y 坐标排序后：77476, 289610, 413356, 550396, 567225, **597006**, 613747, 706822, 766290, 914746, 969978。N=11（奇数），中位数为第 6 个（下标 5），即 597006，与输出一致。

## 2. 套圈问题

### 题目描述

平面上有 N 个点（玩具），需要设计一个最大半径的圆环，使得该圆环恰好能套住一个玩具（即圆内严格包含恰好一个点）。若两点重合，半径为 0。

- 点数：2 ≤ N ≤ 100,000
- 输出：半径，精确到小数点后 2 位

### 输入样例

```
4
0 3
3 2
4 0
7 1
0
```

### 输出样例

```
1.12
```

### 解题思路

**核心结论**：最大半径 = 最近点对距离 / 2。

**证明**：设 d_min 为所有点对之间的最小距离，(p, q) 为最近点对（距离 = d_min）。

- 若半径 R > d_min / 2：考虑以某个中心 C、半径为 R 的圆。若 p 在圆内，即 |pC| < R。由三角不等式：d_min = |pq| ≤ |pC| + |Cq| < R + |Cq|，得 |Cq| > d_min − R。要使 q 不在圆内需 |Cq| ≥ R，即 d_min − R > R ⇒ R < d_min / 2。与 R > d_min / 2 矛盾。故任何 R > d_min / 2 的圆若包含 p 则必包含 q。
- 若半径 R = d_min / 2：将圆心置于 p，则 |pC| = 0 < R，而 ∀q ≠ p, |qC| ≥ d_min = 2R > R，恰好包含一个点。

因此问题等价于**求平面最近点对距离**。

### 算法设计

采用**分治法**（Divide and Conquer），O(N log N)：

1. **排序**：按 X 坐标排序所有点
2. **分治**：将点集从中间分成左右两半，递归求各自的最近距离 d_L, d_R，取 d = min(d_L, d_R)
3. **合并（跨中线）**：收集所有距离中线小于 d 的点，按 Y 坐标排序，检查每个点与其后距离小于 d 的点的距离，更新 d
4. 小规模（≤3 个点）时暴力计算

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(N log² N) 或优化后 O(N log N) |
| 空间复杂度 | O(N) |

### 正确性验证

样例四点：(0,3), (3,2), (4,0), (7,1)。最近点对为 (3,2) 和 (4,0)，距离 √5 ≈ 2.236。半径 = √5 / 2 ≈ 1.118 ≈ 1.12，与输出一致。

## 3. 数字三角形问题

### 题目描述

给定 n 行数字三角形，从顶部出发，每次向下走一步（正下方或右下方），求一条路径使得经过的数字之和最大。

- 行数：1 ≤ n ≤ 100
- 数字范围：0~99

### 输入样例

```
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5
```

### 输出样例

```
30
```

### 解题思路

经典的**动态规划**问题。

**状态定义**：dp[i][j] 表示从位置 (i, j) 出发到达底层的最优路径和。

**状态转移方程**：

```
dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])
```

**边界条件**：dp[n-1][j] = a[n-1][j]（最后一层直接等于原数）

**最优子结构**：从 (i,j) 出发到达底层的最优路径 = 当前位置的数字 + 从下一层可选择的两条路径中较大的那条。

### 递推过程演示

```
原始三角形：         DP自底向上：
    7                  30
   3 8               23  21
  8 1 0            20  13  10
 2 7 4 4          7  12  10  10
4 5 2 6 5       4   5   2   6   5
```

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(n²) |
| 空间复杂度 | O(n²)，可优化到 O(n) |

## 4. 租用游艇问题

### 题目描述

长江上有 n 个游艇出租站 1, 2, …, n。游客从站 i 租艇可在下游任意站 j（j > i）归还，租金为 r(i, j)。求从站 1 到站 n 的最少租金。

- 站点数：n ≤ 200
- 输入：第 1 行 n，后续 n−1 行为上三角矩阵 r(i, j)

### 输入样例

```
3
5 15
7
```

租金矩阵（上三角）：
- r(1,2) = 5, r(1,3) = 15, r(2,3) = 7

### 输出样例

```
12
```

### 解题思路

这是一个 **DAG（有向无环图）上的最短路径**问题。

**状态定义**：dp[j] = 从站 1 到站 j 的最少租金。

**状态转移方程**：

```
dp[1] = 0
dp[j] = min{ dp[i] + r(i, j) }  for all 1 ≤ i < j
```

因为只能从上游（编号小）到下游（编号大），天然的拓扑序，直接递推即可。

### 递推过程

```
dp[1] = 0
dp[2] = min(dp[1] + 5) = 5
dp[3] = min(dp[1] + 15, dp[2] + 7) = min(15, 12) = 12
```

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(n²) |
| 空间复杂度 | O(n²) 存储租金矩阵 |

## 5. 矩阵链乘问题

### 题目描述

给定 N 个矩阵的维度链 A₁(A_{k} × A_{k+1})，求完全括号化方案使矩阵连乘的标量乘法次数最少。

- 矩阵个数：1 ≤ N ≤ 100
- 维度范围：1 ≤ A_k ≤ 2000
- 保证结果唯一且 M < 2³¹

### 输入样例

```
6
30 35 15 5 10 20 25
```

矩阵：A₁: 30×35, A₂: 35×15, A₃: 15×5, A₄: 5×10, A₅: 10×20, A₆: 20×25

### 输出样例

```
15125
((A1(A2A3))((A4A5)A6))
```

### 解题思路

经典的**区间动态规划**。

**状态定义**：m[i][j] = 计算 A_i A_{i+1} … A_j 的最小标量乘法次数。

**状态转移方程**：

```
m[i][i] = 0  （单个矩阵无需计算）
m[i][j] = min{ m[i][k] + m[k+1][j] + p[i-1] × p[k] × p[j] }
          for i ≤ k < j
```

其中 p[i−1] × p[k] × p[j] 是合并左右两部分结果矩阵的乘法代价。

**记录分割点**：s[i][j] 记录最优括号方案的分割位置 k，用于递归构建括号表达式。

### 括号重构

从 s[1][N] 开始递归：对于区间 [i, j]，在 s[i][j] 处分割，递归输出左半部分和右半部分，外层加括号（若 i ≠ j）。

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(N³) |
| 空间复杂度 | O(N²) 存储 m 和 s |

## 6. 石子合并问题

### 题目描述

圆形操场周围摆放 n 堆石子，每次只能合并**相邻**的两堆，得分为合并后新堆的石子数。求将所有石子合并成一堆的**最小得分**和**最大得分**。

- 堆数：1 ≤ n ≤ 100

### 输入样例

```
36
53 49 2 9 9 30 2 35 1 46 39 46 42 33 13 41 35 57 38 59 15 40 18 6 46 30 53 31 34 57 41 20 1 42 59 46
```

### 输出样例

```
5913
24595
```

### 解题思路

这是**环形区间 DP** 的经典问题。

#### 破环成链

将环形转化为线性：将原数组 a[0…n−1] 复制一份拼接到后面，得到长度为 2n 的数组。这样环形中任意起点、长度为 n 的区间都对应一个线性子区间。

#### 状态定义

- dp_min[i][j]：合并区间 [i, j] 内所有石子堆的最小得分
- dp_max[i][j]：合并区间 [i, j] 内所有石子堆的最大得分

#### 状态转移方程

设 sum[i..j] = Σ_{t=i}^{j} a[t]（用前缀和快速计算），则有：

```
dp_min[i][i] = dp_max[i][i] = 0  （单堆无需合并）

dp_min[i][j] = min{ dp_min[i][k] + dp_min[k+1][j] + sum[i..j] }  i ≤ k < j
dp_max[i][j] = max{ dp_max[i][k] + dp_max[k+1][j] + sum[i..j] }  i ≤ k < j
```

**含义**：最后一次合并发生在位置 k 之后，将 [i, k] 和 [k+1, j] 各自已合并成的两堆合并为一堆，此次合并的代价为整个区间的石子总和 sum[i..j]。

#### 最终答案

```c
ans_min = min{ dp_min[i][i+n-1] }  for i = 0, 1, ..., n-1
ans_max = max{ dp_max[i][i+n-1] }  for i = 0, 1, ..., n-1
```

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(N³)（区间长度 × 起点 × 分割点） |
| 空间复杂度 | O(N²) 存储 dp_min 和 dp_max |

## 7. 活动调度问题

### 题目描述

给定 N 个活动，每个活动占用时间区间为 [S_i, F_i)，需要使用若干个教室安排所有活动。要求求出所需教室的最小数量。

- 活动数：1 ≤ N ≤ 1,000,000
- 时间范围：0 ≤ S_i < F_i ≤ 2,000,000,000
- 区间为左闭右开 [S_i, F_i)，因此一个活动在 t 时刻结束，另一个活动可以在 t 时刻开始并复用同一间教室

### 输入样例

```
11
1 4
3 5
0 6
5 7
3 8
5 9
6 10
8 11
8 12
2 13
12 14
```

### 输出样例

```
5
```

### 解题思路

所需教室的最小数量等于任意时刻同时进行的活动最大数量，即**区间最大重叠数**。

可以将所有开始时间和结束时间分别排序，然后用两个指针扫描：

- 若下一个开始时间 `start[i] < finish[j]`，说明新活动开始时最早结束的活动尚未结束，需要新增一个正在占用的教室
- 若 `start[i] >= finish[j]`，说明已有活动已经结束，可以先释放一个教室

特别注意区间是 [S_i, F_i)，所以当 `start[i] == finish[j]` 时，不产生重叠，应该先处理结束时间，让教室被复用。

### 算法设计

1. 读入所有活动的开始时间数组 `start[]` 和结束时间数组 `finish[]`
2. 分别对两个数组升序排序
3. 使用双指针 `i, j` 扫描：
   - `i` 指向当前待处理的开始时间
   - `j` 指向当前最早的结束时间
4. 用 `rooms` 表示当前正在占用的教室数，用 `answer` 记录最大值
5. 扫描结束后，`answer` 即为最少教室数

### 样例过程

按时间扫描时，同时进行活动数的最大值出现在时间段 [3,4)：

```
[0,6), [1,4), [2,13), [3,5), [3,8)
```

此时共有 5 个活动同时进行，因此至少需要 5 间教室；扫描算法也会得到最大占用数 5。

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(N log N)，主要来自两次排序 |
| 空间复杂度 | O(N)，存储开始时间和结束时间 |

## 8. 小游戏

### 题目描述

城堡中的道路形成一棵无向树。需要在结点上放置最少数量的士兵，使得每条边至少有一个端点放置了士兵，也就是所有道路都能被看到。

- 结点数：0 < n ≤ 1500
- 结点编号：0 到 n−1
- 每条边在输入中只出现一次
- 输入包含多组数据，直到文件结束

### 输入样例

```
4
0:(1) 1
1:(2) 2 3
2:(0)
3:(0)
5
3:(3) 1 4 2
1:(1) 0
2:(0)
0:(0)
4:(0)
```

### 输出样例

```
1
2
```

### 解题思路

每个士兵放在一个结点上，可以覆盖与该结点相连的所有边。要求每条边至少被一个端点覆盖，这正是树上的**最小点覆盖**问题。

对于一般图，最小点覆盖较难；但本题图结构是一棵树，可以用**树形动态规划**在线性时间内解决。

### 状态定义

任选一个结点作为根，例如 0 号结点。设：

- `dp0[u]`：在以 u 为根的子树中，u 不放士兵时覆盖所有子树边所需的最少士兵数
- `dp1[u]`：在以 u 为根的子树中，u 放士兵时覆盖所有子树边所需的最少士兵数

### 状态转移方程

对于 u 的每个儿子 v：

```
dp0[u] += dp1[v]
dp1[u] += min(dp0[v], dp1[v])
```

含义：

- 如果 u 不放士兵，那么边 (u, v) 必须由 v 来覆盖，所以 v 必须放士兵
- 如果 u 放士兵，那么边 (u, v) 已经被 u 覆盖，v 放不放都可以，取较小值

边界条件：

```
dp0[leaf] = 0
dp1[leaf] = 1
```

最终答案：

```
min(dp0[root], dp1[root])
```

若 n = 1，树中没有边，不需要放置士兵，答案为 0。

### 算法设计

1. 读取每组数据的 n
2. 对每一行读入结点编号、相邻结点数量以及相邻结点列表
3. 由于题目每条边只出现一次，建图时需要加入两条有向边，形成无向邻接表
4. 从 0 号结点 DFS，递归计算 `dp0` 和 `dp1`
5. 输出 `min(dp0[0], dp1[0])`

### 样例解释

第一组数据的树为：

```
0 - 1
    |\
    2 3
```

只需要在结点 1 放 1 个士兵，就能覆盖边 (0,1)、(1,2)、(1,3)，所以答案为 1。

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(N)，每个结点和每条边只访问常数次 |
| 空间复杂度 | O(N)，存储邻接表和 DP 数组 |

## 算法思想总结

| 问题 | 算法类别 | 核心技巧 | 时间复杂度 |
|------|----------|----------|-----------|
| 油井问题 | 选择算法 | L1中位数性质 + Quickselect | O(N) |
| 套圈问题 | 计算几何 + 分治 | 最近点对 → 最大半径 | O(N log N) |
| 数字三角形 | 动态规划 | 自底向上递推 | O(N²) |
| 租用游艇 | 动态规划 / DAG最短路 | 拓扑序递推 | O(N²) |
| 矩阵链乘 | 区间动态规划 | 最优子结构 + 括号重构 | O(N³) |
| 石子合并 | 环形区间DP | 破环成链 + 前缀和优化 | O(N³) |
| 活动调度 | 贪心 / 扫描线 | 排序开始结束时间 + 最大重叠数 | O(N log N) |
| 小游戏 | 树形动态规划 | 树上最小点覆盖 | O(N) |

### 动态规划三要素

以上 DP 问题均满足：

1. **最优子结构**：问题的最优解包含子问题的最优解
2. **无后效性**：子问题的解一旦确定，不受后续决策影响
3. **重叠子问题**：不同决策路径会重复遇到相同的子问题

### 环形DP通用技巧

对于环形结构（如石子合并），标准做法是**破环成链**：
- 将数组扩容为原来的 2 倍，a[i+n] = a[i]
- 在长度为 2n 的数组上做线性 DP
- 最终在 dp[i][i+n-1] (i = 0…n-1) 中取最优值
