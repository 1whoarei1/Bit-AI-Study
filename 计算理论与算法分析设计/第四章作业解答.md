# 第四章作业解答

## 1. Fibonacci 频率的 Huffman 编码

前 8 个 Fibonacci 数为：

\[
1,1,2,3,5,8,13,21
\]

对应字符：

\[
a,b,c,d,e,f,g,h
\]

| 字符 | 频率 | Huffman 编码 |
|---|---:|---|
| h | 21 | 0 |
| g | 13 | 10 |
| f | 8 | 110 |
| e | 5 | 1110 |
| d | 3 | 11110 |
| c | 2 | 111110 |
| a | 1 | 1111110 |
| b | 1 | 1111111 |

其中 `a` 和 `b` 的编码可以互换。

推广到 \(n\) 个字符，若频率为前 \(n\) 个 Fibonacci 数：

\[
F_1,F_2,\dots,F_n
\]

则 Huffman 树仍然是链式结构。频率最大的字符 \(x_n\) 编码长度为 1，次大的 \(x_{n-1}\) 编码长度为 2，依次类推，最小的两个字符 \(x_1,x_2\) 编码长度都为 \(n-1\)。

一种编码形式为：

\[
x_n: 0
\]

\[
x_{k}: \underbrace{11\cdots 10}_{n-k+1\text{位}}
\]

\[
x_1: \underbrace{11\cdots 11}_{n-1\text{位}}
\]

即最大的字符编码最短，最小的两个字符编码最长。

## 2. 特殊 0-1 背包问题的有效算法

已知物品按重量递增排列：

\[
w_1 \le w_2 \le \cdots \le w_n
\]

而价值恰好降序排列：

\[
v_1 \ge v_2 \ge \cdots \ge v_n
\]

背包容量为 \(C\)。

由于前面的物品更轻且价值更高

最优解一定是某个前缀：

\[
\{1,2,\dots,k\}
\]

其中 \(k\) 是满足：

\[
\sum_{i=1}^k w_i \le C
\]

的最大整数。

算法如下：

```text
sumWeight = 0
sumValue = 0

for i = 1 to n:
    if sumWeight + w[i] <= C:
        sumWeight += w[i]
        sumValue += v[i]
    else:
        break

输出选择的物品 1 到 i-1，以及最大价值 sumValue
```

时间复杂度为：

\[
O(n)
\]

正确性说明：

任取一个可行解，若它包含 \(k\) 个物品，则这 \(k\) 个物品的总重量至少为前 \(k\) 个最轻物品的总重量：

\[
\sum_{i=1}^k w_i
\]

同时它的总价值至多为前 \(k\) 个最高价值物品的总价值：

\[
\sum_{i=1}^k v_i
\]

因此，在所有选 \(k\) 个物品的方案中，选择前 \(k\) 个物品最优。又因为价值均为正，应该尽可能多地选择物品。所以取满足容量限制的最大 \(k\)，即为最优解。

## 3. 两艘船情形下贪心算法是否仍最优？

不能保证最优。

一艘船的最优装载问题中，若目标是装入尽可能多的集装箱，按重量从小到大贪心选择是最优的。

但推广到两艘船时，还需要考虑如何把集装箱分配到两艘船上。仅仅按重量从小到大贪心，可能导致空间分配不合理，从而错过最优方案。

反例：

设两艘船容量分别为：

\[
C_1 = 10,\quad C_2 = 10
\]

集装箱重量为：

\[
2,3,7,8,8
\]

如果按重量从小到大贪心，并优先装入第一艘船：

第一艘船装：

\[
2+3=5
\]

然后装 7 会超过 10，于是尝试第二艘船：

第二艘船装：

\[
7
\]

再装 8 超过 10，停止或无法继续装入。

此时只装了 3 个集装箱：

\[
2,3,7
\]

但最优装法是：

第一艘船装：

\[
2+8=10
\]

第二艘船装：

\[
3+7=10
\]

一共装入 4 个集装箱。

所以，将一艘船情形下的贪心算法直接推广到两艘船时，不一定能得到最优解。

## 4. 最优分解问题

问题：将正整数 \(n\) 分解为若干互不相同的自然数之和，使这些数的乘积最大。

例如：

\[
10 = 2+3+5
\]

最大乘积为：

\[
2 \times 3 \times 5 = 30
\]

### 基本思想

为了使乘积最大，应尽量把 \(n\) 分解成从 2 开始的连续自然数：

\[
2,3,4,\dots,k
\]

因为在和固定的情况下，因子越接近，乘积越大；同时不能使用相同的数，所以应选取尽量连续的不同整数。

设：

\[
2+3+\cdots+k \le n
\]

并且：

\[
2+3+\cdots+k+(k+1)>n
\]

令剩余值为：

\[
r = n - (2+3+\cdots+k)
\]

然后将剩余的 \(r\) 从后往前依次加到这些数上，使它们仍然互不相同。

### 算法

1. 从 2 开始依次取数：2, 3, 4, ...
2. 直到再加入下一个数会超过 \(n\)。
3. 得到初始分解。
4. 将剩余部分从最大的数开始依次加 1。
5. 计算所有数的乘积。

### 伪代码

```text
read n

list = []
sum = 0
i = 2

while sum + i <= n:
    list.append(i)
    sum += i
    i += 1

r = n - sum

从 list 的最后一个元素开始向前，每次加 1，直到 r = 0

product = 1
for x in list:
    product *= x

output product：
```
