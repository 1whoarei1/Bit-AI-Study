# 第 3 章作业题目与解答

## 题目一：整数线性规划问题

### 题目

考虑如下整数线性规划问题：

给定序列\(a_1,a_2,\ldots,a_n\)、\(c_1,c_2,\ldots,c_n\)和整数 \(b\)，求

\[
\max c_1x_1+c_2x_2+\cdots+c_nx_n
\]

满足

\[
a_1x_1+a_2x_2+\cdots+a_nx_n \le b
\]

其中 \(x_i\) 为非负整数。

### 解答

该问题可以看作完全背包问题。每个变量 \(x_i\) 表示第 \(i\) 类物品选择的个数，\(a_i\) 表示该类物品占用的容量，\(c_i\) 表示该类物品的价值，背包容量为 \(b\)。由于 \(x_i\) 可以取任意非负整数，所以每类物品可以选择多次。

它与 0-1 背包问题的主要区别在于变量的取值范围不同。0-1 背包中每个物品最多只能选一次，即 \(x_i \in \{0,1\}\)；而本题中 \(x_i\) 是非负整数，即 \(x_i=0,1,2,\ldots\)，所以同一种物品可以被选多次。因此本题对应的是完全背包问题，而不是 0-1 背包问题。

令

\[
dp[j]
\]

表示容量不超过 \(j\) 时可以得到的最大目标函数值。初始时

\[
dp[j]=0,\quad 0 \le j \le b
\]

对每个变量 \(i\)，由于它可以被选择多次，因此按照容量从小到大更新：

\[
dp[j]=\max(dp[j],dp[j-a_i]+c_i),\quad a_i \le j \le b
\]

这里容量 \(j\) 必须从小到大枚举，这样 \(dp[j-a_i]\) 可能已经包含第 \(i\) 类物品，从而允许继续选择第 \(i\) 类物品。若是 0-1 背包，则应从大到小枚举容量，避免同一个物品在一轮中被重复选择。

最终答案为

\[
dp[b]
\]

算法伪代码如下：

```c
for j = 0 to b:
    dp[j] = 0 	//初始化

for i = 1 to n:
    for j = a[i] to b:
        dp[j] = max(dp[j], dp[j-a[i]] + c[i])

return dp[b]
```

时间复杂度为

\[
O(nb)
\]

空间复杂度为

\[
O(b)
\]

因此，当 \(b\) 作为数值规模参与计算时，该问题可以用动态规划求解，算法是伪多项式时间算法。

## 题目二：数字三角形问题

### 题目

给定一个由 \(n\) 行数字组成的数字三角形，设计一个算法，计算从三角形顶至底的一条路径，使该路径经过的数字和最大。

输入文件 `input.txt` 的第 1 行是数字三角形的行数 \(n\)，其中 \(1 \le n \le 100\)。接下来 \(n\) 行是数字三角形各行中的数字，所有数字在 0 到 99 之间。

输出文件 `output.txt` 的第 1 行输出计算出的最大值。

### 解答

设三角形中第 \(i\) 行第 \(j\) 个数字为 \(a[i][j]\)。令

\[
dp[i][j]
\]

表示从位置 \((i,j)\) 出发，到达底部所能得到的最大路径和。

对于最后一行，有

\[
dp[n][j]=a[n][j],\quad 1 \le j \le n
\]

对于其他位置，只能走到下一行的相邻两个位置，即 \((i+1,j)\) 或 \((i+1,j+1)\)，所以状态转移方程为

\[
dp[i][j]=a[i][j]+\max(dp[i+1][j],dp[i+1][j+1])
\]

最终答案为

\[
dp[1][1]
\]

时间复杂度为

\[
O(n^2)
\]

空间复杂度为

\[
O(n^2)
\]

### 参考程序

```cpp
#include <stdio.h>

#define MAX_N 100

int a[MAX_N][MAX_N];
int dp[MAX_N][MAX_N];

int max(int a, int b) {
    return a > b ? a : b;
}

int main() {
    int n;
    scanf("%d", &n);

    for (int i = 0; i < n; i++)
        for (int j = 0; j <= i; j++)
            scanf("%d", &a[i][j]);

    /* 初始化最底层 */
    for (int j = 0; j < n; j++)
        dp[n - 1][j] = a[n - 1][j];

    /* 自底向上递推 */
    for (int i = n - 2; i >= 0; i--)
        for (int j = 0; j <= i; j++)
            dp[i][j] = a[i][j] + max(dp[i + 1][j], dp[i + 1][j + 1]);

    printf("%d\n", dp[0][0]);

    return 0;
}
```

## 题目三：租用游艇问题

### 题目

长江游艇俱乐部在长江上设置了 \(n\) 个游艇出租站 \(1,2,\ldots,n\)。游客可在这些游艇出租站租用游艇，并在下游的任意一个游艇出租站归还游艇。出租站 \(i\) 到出租站 \(j\) 之间的租金为 \(r(i,j)\)，其中 \(1 \le i < j \le n\)。

要求设计一个算法，计算从出租站 1 到出租站 \(n\) 所需的最少租金，并分析算法复杂性。

输入文件 `input.txt` 的第 1 行是正整数 \(n\)，其中 \(n \le 200\)。接下来 \(n-1\) 行给出 \(r(i,j)\)，其中 \(1 \le i < j \le n\)。

输出文件 `output.txt` 输出从出租站 1 到出租站 \(n\) 的最少租金。

### 解答

该问题可以看作有向无环图上的单源最短路径问题。出租站编号从上游到下游递增，只能从编号小的站点到编号大的站点，因此图中不存在环。

令

\[
dp[j]
\]

表示从出租站 1 到出租站 \(j\) 所需的最少租金。

初始条件为

\[
dp[1]=0
\]

对于 \(j>1\)，最后一次到达 \(j\) 一定是从某个站点 \(i\) 直接租到 \(j\)，其中 \(1 \le i < j\)。因此状态转移方程为

\[
dp[j]=\min_{1 \le i < j}\{dp[i]+r(i,j)\}
\]

最终答案为

\[
dp[n]
\]

时间复杂度为

\[
O(n^2)
\]

空间复杂度为

\[
O(n^2)
\]

### 参考程序

```cpp
#include <stdio.h>
#include <limits.h>

#define MAX_N 200
#define INF INT_MAX

int r[MAX_N + 1][MAX_N + 1];
int dp[MAX_N + 1];

int min(int a, int b) {
    return a < b ? a : b;
}

int main() {
    int n;
    scanf("%d", &n);

    for (int i = 1; i < n; i++) {
        for (int j = i + 1; j <= n; j++) {
            scanf("%d", &r[i][j]);
        }
    }

    dp[1] = 0;
    for (int i = 2; i <= n; i++)
        dp[i] = INF;

    for (int j = 2; j <= n; j++) {
        for (int i = 1; i < j; i++) {
            if (dp[i] != INF && r[i][j] != 0)
                dp[j] = min(dp[j], dp[i] + r[i][j]);
        }
    }

    printf("%d\n", dp[n]);

    return 0;
}
```
