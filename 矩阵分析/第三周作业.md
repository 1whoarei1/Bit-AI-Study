## **题目**：设 $A \in M_n$，$A = QR$ 是 QR 分解，$R = [r_{ij}]$，按列划分 $A = [a_1 \ldots a_n],\; Q = [q_1 \ldots q_n],\; R = [r_1 \ldots r_n]$。说明 $|\det(A)| = \det(R) = r_{11} \cdots r_{nn}$。

**解答**：

由行列式乘积性质：$\det(A) = \det(QR) = \det(Q)\det(R)$。

$Q$ 是正交矩阵，$Q^T Q = I$，取行列式得 $|\det(Q)|^2 = \det(I) = 1$，故 $|\det(Q)| = 1$。因此：

$$|\det(A)| = |\det(Q)| \cdot |\det(R)| = |\det(R)|$$

$R$ 是上三角矩阵，$\det(R) = r_{11} r_{22} \cdots r_{nn}$。由 Gram-Schmidt 过程，$r_{ii} = \|\tilde{q}_i\|_2 \geq 0$（当 $A$ 列满秩时严格 $>0$），故 $\det(R) = |\det(R)|$。

综上：$|\det(A)| = \det(R) = r_{11} r_{22} \cdots r_{nn}$。



## **题目**：设 $A \in M_{m,n}$，$\sigma_1(A) \geq \cdots \geq \sigma_q(A)$ 是有序排列的奇异值（$q = \min\{m,n\}$），证明：$$\sigma_1(A) = \max\{|x^*Ay| : x \in \mathbb{C}^m,\; y \in \mathbb{C}^n,\; \|x\|_2 = \|y\|_2 = 1\}$$

**解答**：

由 SVD，存在酉矩阵 $U \in M_m$、$V \in M_n$ 使 $A = U\Sigma V^*$，其中 $\Sigma = \operatorname{diag}(\sigma_1, \ldots, \sigma_q) \in M_{m,n}$。

对任意单位向量 $x, y$（$\|x\|_2 = \|y\|_2 = 1$），令 $u = U^*x$，$v = V^*y$。由酉不变性，$\|u\|_2 = \|v\|_2 = 1$，且：

$$|x^*Ay| = |u^*\Sigma v| = \Bigl|\sum_{i=1}^{q} \sigma_i \bar{u}_i v_i\Bigr| \leq \sum_{i=1}^{q} \sigma_i |u_i||v_i| \leq \sigma_1 \sum_{i=1}^{q} |u_i||v_i|$$

由 Cauchy-Schwarz：$\sum |u_i||v_i| \leq \sqrt{\sum |u_i|^2}\sqrt{\sum |v_i|^2} \leq 1$。故 $|x^*Ay| \leq \sigma_1$，即 $\max |x^*Ay| \leq \sigma_1$。

另一方面，取 $x = Ue_1$（$U$ 的第一列），$y = Ve_1$（$V$ 的第一列），则 $\|x\|_2 = \|y\|_2 = 1$ 且：

$$|x^*Ay| = |e_1^T \Sigma e_1| = \sigma_1$$

上界可达，证毕。
